# دوائي 💊

تطبيق React Native (Expo) لتذكير كبار السن بمواعيد الدواء، ويتصل تلقائياً برقم الطوارئ إذا ما تم الرد على التنبيه.

## الشاشات
1. **الترحيب وتسجيل الدخول** (`WelcomeScreen`)
2. **بيانات الطوارئ**: رقم الطوارئ، رقم المستفيد، بريد التقرير اليومي (`SettingsScreen`)
3. **أدويتي**: إضافة الأدوية ومواعيدها وتأكيد الجرعة (`MedsScreen`)

الألوان: أخضر `#2E7D5B` ورمادي `#5B6661`.

## التشغيل
```bash
npm install
npx expo prebuild
npx expo run:android
```
> لازم Development Build، لأن الاتصال التلقائي يحتاج مكتبة native ولا يعمل داخل Expo Go.

## حدود مهمة
- **الاتصال التلقائي يعمل على أندرويد فقط** (صلاحية `CALL_PHONE`). آيفون يمنع الاتصال بدون موافقة المستخدم، فيفتح شاشة الاتصال فقط.
- في أندرويد، أوقف توفير البطارية للتطبيق وفعّل "التنبيهات الدقيقة" حتى يشتغل التصعيد والتطبيق مغلق.
- التسجيل حالياً محلي للتجربة. للإنتاج استخدم Firebase Auth.
- التقرير اليومي يحتاج خادم: عدّل `REPORT_URL` في `src/services/report.js` وشغّل `server-example.js` (أو Firebase Functions).
- جرّب الاتصال على رقم تجريبي قبل الاعتماد عليه في حالة حقيقية.
